# Product Overview

This is an AI agent application for Windows that's currently in early development stages. The project serves as a learning platform to understand Flutter development and BLoC state management through hands-on implementation.

## Current Features
- Chat interface with AI integration
- Dark/light theme support with custom Material 3 design
- Code highlighting and mathematical expression rendering
- Persian/Farsi font support (Vazir family)
- Window management for desktop platforms

## Planned Architecture
The app will have two operational modes:
- **Online Mode**: Uses cloud-based models like Gemini through APIs for better performance
- **Offline Mode**: Uses local Small Language Models (SLMs) for privacy and offline functionality

## Future Vision
The end goal is a comprehensive AI agent integrated with various tools and capabilities, built step-by-step as a learning project to master Flutter development patterns and state management.
